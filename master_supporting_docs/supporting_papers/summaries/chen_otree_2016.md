# Chen, Schonger & Wickens (2016) — *oTree: An open-source platform*

## Type

**Software / methodological paper** introducing oTree, an open-source platform for running incentivised experiments in lab, online, field, or classroom settings.

## Why oTree

- **Replaces z-Tree** (Fischbacher 2007) for many use cases.
- **Browser-based**: runs on any device with a browser (desktop, tablet, phone).
- **Python-based**: open-source, easy to read and modify.
- **Internet-deployable**: enables online experiments, not just lab.
- **Free**: zero licensing cost.

## Key features

1. Standard game templates (dictator, trust, public-goods, ultimatum, etc.).
2. Strategy method support.
3. Customisable payment mechanisms.
4. Built-in random assignment, attention checks, and demographic surveys.
5. Open source (MIT license).

**(2) Browser-based + online run.** The manuscript's design (Prolific, online, desktop-restricted) leverages oTree's browser-based and online-deployment features. This wouldn't have been possible with z-Tree.

**(3) Strategy-method support.** The manuscript uses the strategy method for Player B's punishment elicitation. oTree supports this natively.
