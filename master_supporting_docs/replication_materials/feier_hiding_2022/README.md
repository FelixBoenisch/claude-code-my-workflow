## Software

Per the paper: experiment programmed in **z-Tree** (Fischbacher 2007); recruitment via **ORSEE** (Greiner et al. 2004); analysis in **Python** (NumPy, SciPy, statsmodels). The notebooks here are Jupyter (.ipynb) files.
