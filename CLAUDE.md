## Core Principles

- **Plan first** — enter plan mode before non-trivial tasks; save plans to `quality_reports/plans/`
- **Verify after** — compile the manuscript and confirm output at the end of every task
- **Single source of truth** — `manuscript/` is authoritative; generated tables and figures derive from `scripts/python/` and are never edited directly
- **Quality gates** — nothing ships below 80/100
- **Python primary** — data analysis uses Python (`scripts/python/`); number scripts sequentially (`01_`, `02_`, …)
- **Preregistration** — lab/survey experiments require a pre-analysis plan; use `/preregister --style osf` or `--style aea-rct` as appropriate
- **[LEARN] tags** — when corrected, save `[LEARN:category] wrong → right` to [MEMORY.md](MEMORY.md)

Cross-session context lives in [MEMORY.md](MEMORY.md); past plans, specs, and session logs are in [quality_reports/](quality_reports/).

## Target Journals

**Primary:** AER, QJE, JPE  
**Fallback:** JEEA, JPubE  

Key style notes:
- AEA journals do **not** use significance stars in tables (since 2018).
- Cluster standard errors at the appropriate unit; report in parentheses.
- Replication packages required at acceptance (AEA Data and Code Availability Policy).

Use `/review-paper --peer AER` (or QJE / JPE / JEEA) to activate the simulated editorial pipeline against a specific journal profile.
