# Single Source of Truth: Paper Workflow

**`manuscript/` is the authoritative source for all content.** Generated outputs (tables, figures) derive from analysis scripts and are never edited directly.

## The SSOT Chain

```
manuscript/*.tex  (SOURCE OF TRUTH — edited directly)
  ├── \input{tables/...}   ← generated by scripts/python/
  ├── \includegraphics{figures/...} ← generated by scripts/python/
  └── Bibliography_base.bib (shared, edited directly)

scripts/python/  (SOURCE OF TRUTH for outputs)
  └── _outputs/ → tables/ and figures/  (derived — never edit directly)
```

**Never edit a table or figure file directly.** If a number looks wrong, fix the script that generated it, re-run, and let the output overwrite.

## Figure and Table Freshness

Before any submission or review pass, verify that all generated files are current:

1. Check that `_outputs/` timestamps are newer than the scripts that created them.
2. If stale: re-run the relevant script and confirm the manuscript compiles cleanly.
3. Spot-check one numeric claim in the text against the corresponding table value.

## Content Fidelity for Submitted Versions

Before sharing any draft:
- Every number in the text must match the corresponding table/figure output exactly.
- Every citation key in `.tex` must resolve in `Bibliography_base.bib`.
- No commented-out stale content left in the manuscript.
